# WORKFLOW

1. Read CLAUDE.md.
2. Load the gmod-particles skill.
3. Identify critical missing information.
4. Ask questions before generation when necessary.
5. Search similar PCFs in examples/.
6. Design the visual layering.
7. Produce only the necessary PCF/assets.
8. Validate structure and performance.
9. Prepare an image/video preview when the environment allows it.
10. Ask for user validation and iterate.

A particle request must not automatically create Lua or gameplay logic.

# VISUAL DESIGN

## Composition

Une bonne particule possède une hiérarchie.

Le joueur doit comprendre immédiatement :
- où est le centre ;
- quelle est la partie principale ;
- quelle est la partie secondaire ;
- dans quelle direction l'effet se déplace.

## Timing

Lorsque pertinent :

INTRO
→ MAIN
→ OUTRO

## Core

Le core porte l'identité principale.

## Glow

Le glow améliore la perception de lumière mais ne doit pas masquer une mauvaise composition.

## Secondary

Les particules secondaires ajoutent de la richesse mais doivent rester subordonnées.

## Sparks

Les sparks doivent renforcer l'énergie et non devenir le sujet principal sans demande.

## Trail

Un trail doit communiquer clairement la direction du mouvement.

## Couleurs

Éviter les mélanges arbitraires.

Une palette principale + une variation secondaire est souvent suffisante.

## Mouvement

Le mouvement doit avoir une intention :
- rotation ;
- expansion ;
- attraction ;
- flottement ;
- oscillation ;
- propulsion ;
- dispersion.

Le hasard ne doit pas remplacer une intention artistique.

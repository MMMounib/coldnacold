# TROUBLESHOOTING

## Effet trop chargé

Vérifier :
- emission ;
- lifetime ;
- particules secondaires ;
- glow ;
- sparks ;
- trails.

## Effet trop plat

Vérifier :
- hiérarchie core/glow ;
- variation de taille ;
- alpha ;
- mouvement ;
- timing ;
- couches secondaires.

## Effet illisible

Vérifier :
- contraste ;
- densité ;
- taille ;
- couleur ;
- vitesse ;
- accumulation.

## Effet trop coûteux

Vérifier :
- particules permanentes ;
- emission ;
- lifetime ;
- operators ;
- trails ;
- culling ;
- draw distance.

## PCF non fonctionnel

Ne pas improviser une correction.

Identifier précisément :
- fichier concerné ;
- structure ;
- champ ;
- référence de matériau ;
- renderer ;
- dépendance.

Puis consulter les références et les exemples du projet.

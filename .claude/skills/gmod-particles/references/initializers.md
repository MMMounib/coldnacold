# INITIALIZERS

Initializers : état de départ des particules.

Familles utiles :
- Lifetime Random
- Radius Random
- Color Random
- Alpha Random
- Rotation Random
- Velocity Random
- Position Within Sphere Random
- Position Within Box Random
- Position Along Ring
- Position Along Path Random

## Règles

- Utiliser uniquement les initializers nécessaires.
- Les valeurs doivent être cohérentes avec la durée et la vitesse.
- Ne pas ajouter du hasard sans intention artistique.
- Une variation contrôlée est généralement préférable à une variation totalement aléatoire.
- Les initializers doivent servir la composition.

# OPERATORS

Operators : évolution des particules pendant leur durée de vie.

Familles utiles :
- Movement Basic
- Alpha Fade In Random
- Alpha Fade Out Random
- Alpha Fade and Decay
- Radius Scale
- Color Fade
- Rotation Spin Roll
- Rotation Spin Yaw
- Velocity Noise
- Oscillate Scalar
- Oscillate Vector
- Pull towards control point
- Movement Rotate Particle Around Axis

## Règles

- Les transitions doivent être progressives sauf intention contraire.
- Ne pas utiliser du noise simplement pour ajouter du mouvement.
- Le mouvement doit correspondre au type d'effet.
- Les fades doivent participer au timing visuel.
- Les operators doivent être compatibles avec la fonction de la couche.

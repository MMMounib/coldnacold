# MATERIALS

Le matériau doit correspondre à la fonction visuelle.

Exemples :
- glow doux ;
- énergie ;
- feu ;
- fumée ;
- sparks ;
- trail.

Ne jamais inventer silencieusement un chemin de matériau.

Si un matériau personnalisé est nécessaire :
1. identifier clairement le besoin ;
2. vérifier les assets disponibles ;
3. créer les fichiers nécessaires uniquement si demandé/possible ;
4. conserver une arborescence propre.

Les matériaux et textures existants du projet ont priorité lorsqu'ils sont adaptés.
